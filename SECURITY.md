# Security Policy

## Overview

The Liquid Glass Personal Finance & Expense Tracker is engineered with strict enterprise security standards to protect sensitive financial records.

## Security Architecture

1. **Local Data Encryption**: All user financial records, transactions, budgets, and preferences are stored in encrypted Hive boxes using AES-256 standards.
2. **Authentication**: Authentication is managed via Firebase OAuth 2.0 and Google Sign-In with token persistence.
3. **Biometric Protection**: Native device biometrics (Face ID / Fingerprint) wrap application state resuming.
4. **Zero-Knowledge Privacy**: No plaintext financial figures or unencrypted credentials are ever transmitted to third-party endpoints.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please notify our security team directly:

- **Email**: security@expensetracker.app
- **Response Time**: Within 24 hours

Please do not report security vulnerabilities through public GitHub issues.
