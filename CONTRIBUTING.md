# Contributing Guidelines

Thank you for contributing to the Liquid Glass Expense Tracker!

## Pull Request Guidelines

1. **Static Analysis**: Run `flutter analyze` locally before submitting a PR. Your PR must return **0 Errors** and **0 Warnings**.
2. **Automated Testing**: Ensure all tests pass by running `flutter test`.
3. **Coding Standards**: Follow standard Flutter and Clean Architecture conventions.
4. **Commit Messages**: Write clear, descriptive commit messages.

## Development Setup

```bash
flutter pub get
flutter analyze
flutter test
```
